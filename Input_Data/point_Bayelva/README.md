## WARNINGS

**Provenance unverified.** The variable written as `tas` comes from
`Donnee/Temp_18y_day.txt`. Whether that file holds 2 m air temperature or
near-surface (1 cm) soil temperature has not been confirmed — the namelist
comment for the related `Boikedata.txt` says "1 cm depth", which would make it
a soil temperature and therefore *not* what FROG expects as an upper boundary
condition. **Verify before using these files for anything but code testing.**

**Processing undocumented.** How the original PANGAEA record was reduced to
the text files under `Donnee/` is unknown: gap filling, aggregation to daily
means and unit handling are all unrecorded.

**Leap days removed.** Four 29 February (2000, 2004, 2008, 2012) were dropped,
and the trailing 2016-01-01 trimmed, so that the series is exactly 18 x 365
steps. FROG has no Gregorian calendar — `timer_mod` knows 360- and 365-day
years only — and `UPDATE_climate_forcing` wraps by array index, so a series
that is not a whole number of years shifts the seasonal cycle on every wrap.
The time axis therefore does not correspond to real dates after 2000-02-28.

**Snow forcing is not yet read by FROG.** As of commit `9919138`,
`spatialvars_init` sets `forcing_snow_thick(:,:) = 1.5` unconditionally under
`#if ( SNOW_EFFECT == 1 )`; see the `[TBD]` comment at `spatialvars_mod.f90:251`.
`forcing_snowthick.nc` is ready but unused until that path is implemented.
